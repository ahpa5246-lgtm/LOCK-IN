# Security

LOCK-IN is a local-first desktop application. It does not transmit focus history, application names, or account data to a remote service.

The application runs with normal user permissions. It does not install a kernel component, change Windows security policy, or disable Windows recovery tools. Task Manager and accessibility utilities remain available.

Session state, statistics, and local error logs are stored under %LocalAppData%\LOCK-IN.

For security issues, use GitHub private vulnerability reporting when it is enabled for this repository, or contact the repository owner privately. Include the affected version, Windows version, reproduction steps, and expected versus actual behavior.
